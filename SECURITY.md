# Security

This repository publishes Windows installers only. Each release ships a
`latest.json` feed with the SHA-256 of that build; the desktop app verifies
the hash before it runs an update.

## Reporting a vulnerability

Do not open a public issue for security reports.

Email or contact **[drog.ai](https://drog.ai)** directly. Include the version
number from **Settings → Updates** and, if you have it, the SHA-256 of the
installer you downloaded.
